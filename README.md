# Salón Recreativo

Farol (póker) y Órdago (mus): roguelikes de cartas para el móvil, instalables como app web (PWA).

- `src/`: los juegos, cada uno en un solo archivo HTML.
- `python3 build.py <versión>`: genera `farol/` y `ordago/` con manifiesto, service worker e iconos.
- `index.html`: portada con los dos juegos y cómo instalarlos.
